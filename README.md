# UI-автотесты «Первого Гипермаркета Мебели»

## Подготовка

Для запуска нужны Node.js с npm, Git Bash и установленный Google Chrome. Открой Git Bash в корне проекта и установи зависимости.

```bash
npm ci
```

## Запуск тестов

| Что запустить | Команда |
| --- | --- |
| Все тесты | `bash run.sh` |
| Все сценарии входа по паролю | `bash run.sh tests/auth/password-signin.spec.ts` |
| Только вход по e-mail | `bash run.sh -g 'Вход по e-mail'` |
| Вход по e-mail в Playwright Inspector | `bash run.sh -g 'Вход по e-mail' --debug` |
| ТК-ВХ-13 без запроса учётных данных | `bash run.sh --no-prompt -g 'ТК-ВХ-13'` |
| ТК-ВХ-13 с видимым окном Chrome | `bash run.sh --no-prompt -g 'ТК-ВХ-13' --headed` |
| Список тестов без запуска | `bash run.sh --list` |
| Справка по скрипту | `bash run.sh --help` |

Без `--headed` и `--debug` Chrome запускается без видимого окна. Скрипт передаёт флаги Playwright, например `-g`, `--headed` и `--debug`, напрямую.

## Учётные данные

`run.sh` запрашивает телефон, e-mail и пароль в терминале. Ввод скрыт, файл `.env` для запуска через скрипт не нужен. Если переменная `PHONE`, `EMAIL` или `PASSWORD` уже задана в окружении, скрипт использует её. Поле, которое не нужно выбранному тесту, можно пропустить клавишей Enter.

Для обоих вариантов ТК-ВХ-09 используй телефон и e-mail одной учётной записи с действующим паролем. Для прогона с реальным паролем не добавляй `--trace on`.
